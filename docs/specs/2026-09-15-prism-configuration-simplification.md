# Prism 配置简化方案

日期：2026-09-15

## 目标

运维人员打开网关后，可以直接修改模型、上游、映射、价格和密钥。保存成功后立即影响下一次请求，不需要理解快照、发布、部署代次、证明或回滚。

## 保留的能力

- 模型按 LLM、图片、视频类型浏览。
- 上游渠道、API Key、模型映射、参数约束和 JSON 映射。
- 用户售价、上游成本、路由优先级和权重。
- 调用日志、异步任务恢复、计费幂等、输入校验、SSRF 防护和审计记录。
- 每次请求在开始时读取一次配置，后续执行使用这份固定配置，避免请求中途被修改。

## 删除的能力

- 配置历史页面和历史快照。
- 编辑时的 fork、publish、prove、activate 流程。
- 配置回滚、待激活状态和部署代次操作页面。
- 上游密钥的身份、密钥版本、轮换证明和加密就绪等日常管理流程。

## 配置写入规则

所有运维编辑都在一个数据库事务内完成，并使用当前行的 `config_version` 做并发保护。写入后直接更新活动配置；失败则整笔事务回滚。审计只记录操作者、对象、字段和结果，不记录密钥内容。

## 密钥规则

上游 API Key 直接保存到 `gw_credentials.secret`。创建和替换接口接收完整值，读取接口不返回 Key，调用日志与审计记录不记录该字段。创建和替换不执行凭据密钥环轮换。只有启用中或停止分配中的凭据尚无明文 Key、仍依赖旧密文时，数据面才要求旧凭据 KEK/HMAC；Payload KEK/HMAC 始终必需。

## 迁移策略

新增迁移增加 `secret` 列，并允许明文凭据保留不带加密 Blob 的兼容版本记录；已应用的历史迁移不修改。已有加密凭据在旧凭据 KEK/HMAC 可用时继续读取，替换后改用明文；无法读取的记录保持不可用，直至管理员替换 Key。已停用的旧密文凭据不会阻止数据面启动。旧发布表暂时保留为数据兼容层，但产品界面和直接编辑接口不再创建新的发布快照；旧 `POST /catalog` 草稿接口仅为客户端兼容保留，不属于当前配置流程。

## 验收重点

1. 修改模型映射后下一次请求使用新映射。
2. 替换或停用 Key 后无需部署操作即可生效。
3. 并发编辑不会覆盖较新的配置。
4. 真实 LLM、图片和视频调用可完成，调用、计费和异步状态可核对。
